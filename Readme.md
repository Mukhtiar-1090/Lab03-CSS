## 🎯 Project Overview
This repository contains all practical lab exercises from **Lab 03 & 04** based on *CSS Fundamentals and Visual Design.*  
Each task demonstrates the use of CSS for creating visually appealing, responsive, and well-structured web designs.

The goal of these labs was to explore **styling techniques**, **visual effects**, and **real-world design principles** to enhance the appearance and interactivity of web pages.

## 🧩 Tasks Overview

### **Task 1: CSS Selectors Practice**
Used various **basic, attribute, and combinator selectors** with pseudo-classes and pseudo-elements to style different elements.

### **Task 2: Typography Showcase**
Implemented **Google Fonts**, various font sizes, text alignment, shadows, and transformations to explore typography.

### **Task 3: Background Gallery**
Created **solid, image, and gradient backgrounds** including multiple layers and blend modes for creative designs.

### **Task 4: Image Styling Portfolio**
Styled images with **rounded corners, borders, shadows, filters, and overlays** with hover transitions.

### **Task 5: Button Styling Collection**
Designed **various button styles** with different shapes, colors, shadows, transitions, and disabled states.

### **Task 6: Form Styling**
Styled a registration form with **custom input fields, focus and success states**, and interactive form elements.

### **Task 7: Card Component Design**
Developed responsive **product/service cards** with shadows, hover effects, and call-to-action buttons.

### **Task 8: Navigation Menu Styling**
Built **horizontal and vertical menus**, dropdowns, and responsive navigation bars with smooth transitions.

### **Task 9: CSS Transform Gallery**
Showcased **2D and 3D transformations**, rotations, scaling, and transition animations.

### **Task 10: Advanced Effects Showcase**
Implemented **gradient text, CSS animations, custom checkboxes, and text clipping effects.**

### **Task 11: Personal Portfolio Styling**
Applied consistent **color scheme, spacing, typography, and image effects** to enhance the Lab 02 portfolio.

### **Task 12: Course Website Styling**
Styled the **course schedule table** with zebra striping, hover effects, color-coding, and responsive layouts.

### **Task 13: GitHub Pages Enhancement**
Enhanced the live GitHub Pages site with **modern design, gradients, responsive layout, and improved readability.**
